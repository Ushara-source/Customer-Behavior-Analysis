# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior to identify purchasing patterns, product preferences, and business opportunities using data analytics tools.

## Objectives
- Analyze customer purchasing patterns and demographics.
- Understand revenue trends and customer spending.
- Identify top-rated products.
- Analyze discount usage and shipping preferences.
- Generate insights to support business decisions.

## Tools and Technologies
- **Python:** Data cleaning and exploratory data analysis using Pandas.
- **SQL / PostgreSQL:** Data querying, filtering, grouping, and analysis.
- **Excel:** Data organization and analysis.
- **Power BI:** Dashboard creation and data visualization.

## Project Workflow
1. Understand the business problem.
2. Clean and prepare the dataset.
3. Perform exploratory data analysis using Python.
4. Analyze customer behavior using SQL.
5. Create a Power BI dashboard.
6. Document findings and business insights.

## Key Analysis Areas
- Customer demographics and purchasing behavior.
- Revenue by gender.
- Discount usage and purchase amounts.
- Top five products by average review rating.
- Purchase behavior by shipping type.
- Customer purchase frequency.

## Files Included
- Business Problem Document
- Customer Shopping Behavior Analysis report
- Project presentation
- SQL queries
- Power BI dashboard
- Supporting project files

## Expected Outcome
This project demonstrates how data analytics can help businesses understand customer preferences, evaluate product performance, and make informed decisions.
